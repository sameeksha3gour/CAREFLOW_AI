# CAREFLOW_AI# CareFlow AI – AI-Powered Healthcare Appointment Assistant

CareFlow AI is an AI-powered, chat-based healthcare appointment assistant designed to simplify doctor discovery and appointment management through natural-language interaction.

The system allows users to find doctors, check doctor-specific availability, book appointments, view existing appointments, reschedule appointments, and cancel appointments through a conversational interface.

## Key Features

- 🔐 User authentication with JWT
- 🤖 AI-powered conversational appointment assistant
- 🩺 Doctor discovery and specialization-based search
- 📅 Doctor-specific appointment calendar
- ⏰ Availability and time-slot checking
- 📌 Appointment booking
- 🔄 Appointment rescheduling
- ❌ Appointment cancellation
- 💬 Persistent conversation management
- 🔗 RESTful backend APIs
- 🗄️ MongoDB-based data persistence
- ⚛️ React.js frontend
- 🟢 Node.js and Express.js backend

## Technology Stack

**Frontend:** React.js, CSS, Vite  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT  
**AI:** LLM-based conversational AI  
**API:** REST APIs

## Project Objective

The objective of CareFlow AI is to move healthcare appointment management from a navigation-heavy interface toward a more intuitive conversational experience, while maintaining controlled backend operations for doctors, availability, and appointments.
